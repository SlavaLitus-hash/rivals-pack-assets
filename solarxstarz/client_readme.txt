========================================================
  solarxstarz — STANDARD PACK for Rivals (Fleasion)   v1.1
========================================================

Thanks for your order! This is a focused Standard pack — it changes only
the items listed below, nothing else in the game is touched.

--------------------------------------------------------
WHAT THIS PACK CHANGES
--------------------------------------------------------
  • Arena texture   — the arena surface, carrying the M4 logo.

  • Skybox          — ALL maps get the Edge of Oblivion sky, with the
                      M4 logo on the top face, so it shows over every
                      map. (Station has its own set of faces; every
                      other map shares one set. On Graveyard /
                      Graveyard SD / Zombie Tower / Westown the game
                      uses a single texture for all four side walls,
                      so those four walls show the same face —
                      expected, not a bug.)

  • Diamond Hands   — the M4 logo replaces the flare image used by the
                      Diamond Hands finisher.

  • Hit sounds      — body hit, and head hit in both of the game's
                      variants (the second is very slightly higher
                      pitched, same as the original pair).

  • Other sounds    — UI confirm, map vote, heal, RPG explosion,
                      duel countdown, queue countdown, portal ambience.

--------------------------------------------------------
WHAT THIS PACK DOES *NOT* TOUCH
--------------------------------------------------------
  Listed so there are no surprises — these are left completely stock:

  • No UI icons, ranks, item slots or map previews.
  • No font changes.
  • No weapon skins, models or animations.
  • No lobby music.
  • Other finishers are untouched — only the Diamond Hands
    flare image is changed.

--------------------------------------------------------
HOW TO IMPORT (Fleasion)
--------------------------------------------------------
  1. Open Fleasion.
  2. Import / Add config  ->  select the file:
        Solarxstarz_Standard_V1.1.json
     (place it in Fleasion's configs folder if you prefer)
  3. Select the preset and make sure it is ENABLED (toggle on).
  4. Press Clear Cache.
  5. Launch the game.

  All assets stream from the cloud (CDN) — no extra files to place,
  you don't need anything except the .json.

--------------------------------------------------------
IMPORTANT: CLEAR THE ROBLOX CACHE BEFORE TESTING
--------------------------------------------------------
  Roblox caches assets on disk. If you skip this you may still see/hear
  the OLD assets and think the pack didn't work.

  1. Fully CLOSE Roblox (quit completely, not just the window).
  2. In Fleasion, remove any older/previous imports of this pack.
  3. Enable "Clear Cache on Launch" in Fleasion (or clear the Roblox
     cache manually), then launch.
  4. Join a match and check the sky / arena / hit sounds.

  "Nothing changed" almost always means a stale cache — clear it and
  relaunch before reporting an issue.

--------------------------------------------------------
HEADS-UP: GAME UPDATES
--------------------------------------------------------
  Rivals sometimes changes the internal IDs of its assets when the game
  updates. If that happens, one or two things in this pack may stop
  applying (usually the skybox or a hit sound). This is NOT a broken
  pack — the IDs just moved. Message me and I'll patch the affected
  IDs quickly.
