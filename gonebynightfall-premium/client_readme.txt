----------------------------------------------------------
WHAT THIS PACK CHANGES
----------------------------------------------------------
  SKYBOX  — the black hole sky on ALL maps.
            The black hole itself sits on the FRONT face; the other
            faces are the deep-space starfield around it.
            Note: on Graveyard / Graveyard SD / Zombie Tower / Westown
            the game uses ONE texture for all four side walls, so those
            four walls all show the same face. That is a game limitation,
            not a bug.

  ARENA   — the arena surface texture is replaced with your black block.

  ICONS   — Level icon  : your ringed-planet icon.
            Streak icon : your galaxy icon (covers both streak variants
                          the game uses).

  REMOVED — these UI elements are hidden completely:
            • the round timer — both the hourglass icon and the plate
              behind it
            • the weapon panel background
            • the five item slot backdrops

            Note: the timer DIGITS are text, not an image, so they stay.
            Nothing in Fleasion can remove them.

  DIALOG    — the chicken dialog portrait is replaced with your own
              avatar render, fitted to the original 1024x512 canvas.

  SOUNDS    — the ASMR FPS Redux sound set: hit and headshot markers,
              the three kill voices, heal, RPG boom, both countdowns,
              portal ping and the two UI clicks. Intro theme, lobby music
              and the map ambience are silenced, as in that set.

  Not included in this build (agreed): watermark.

HOW TO IMPORT (Fleasion)
----------------------------------------------------------
  1. Open Fleasion.
  2. Import / Add config  ->  select the file:
        starrygothacked.json
  3. Make sure the config is ENABLED (toggle on).
  4. All assets stream from the cloud (CDN) — no extra files to place,
     you don't need anything except the .json.

----------------------------------------------------------
IMPORTANT: CLEAR THE ROBLOX CACHE BEFORE TESTING
----------------------------------------------------------
  Roblox caches assets on disk. If you skip this you may still see the
  OLD assets and think the pack didn't work.

  1. Fully CLOSE Roblox (quit completely, not just the window).
  2. In Fleasion, remove any older/previous imports of this pack.
  3. Enable "Clear Cache on Launch" in Fleasion (or clear the Roblox
     cache manually), then launch.
  4. Join a match and check the sky, the arena and the UI.

  "Nothing changed" almost always means a stale cache — clear it and
  relaunch before reporting an issue.

----------------------------------------------------------
ABOUT THE TWO ICONS
----------------------------------------------------------
  Your level and streak icons are pure black artwork, kept exactly as
  you sent them — not recoloured, only resized to the game's canvas.
  Rivals tints these icons, and a tint cannot lighten black, so on dark
  UI panels they will read as dark silhouettes. If you'd rather have
  them light (white / light grey) so they pop against the panel, say the
  word — that's a quick swap, the pack link stays the same.

----------------------------------------------------------
HEADS-UP: GAME UPDATES
----------------------------------------------------------
  Rivals sometimes changes the internal IDs of its assets when the game
  updates. If that happens, one or two things in this pack may stop
  applying (usually the skybox). This is NOT a broken pack — the IDs
  just moved. Message me and I'll patch the affected IDs quickly.
